# Vriksh Rakshak Dal Sewa Trust
A responsive website for the Trust's tree planting, tree protection, and community work in the Braj region.

## Features
- Mission, tree care, plantation, impact, gallery, and story pages.
- Volunteer, contact, and donation information, with legal and trust details.
- Mobile-friendly layouts, Hindi support, original branding, and offline support.

## Stack
React 19, TypeScript, Vite, TanStack Start/Router, and Tailwind CSS 4.

## Commands
- `npm install`: install dependencies; `npm run dev`: start the local server.
- `npm run lint`: check code; `npm run build`: create the production build.
- `npm run preview`: preview the production build locally.
